# mmh-fedex-login

Static OAuth consent page for the MMH FedEx Reporting MCP connector (Supabase project `trcejwpnezjuirkilssl`).

- `oauth/consent.html`: Supabase OAuth 2.1 authorization path. Signs in with Google (MMH Workspace only), then approves or denies the Claude/ChatGPT request.
- Only public values live here: the project URL and its publishable key. Access control is server-side.
